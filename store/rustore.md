# RuStore — публикация

Консоль разработчика: https://console.rustore.ru (вход через VK ID). Регистрация бесплатная.

## 1. Регистрация разработчика (делаешь ты)
- Тип аккаунта: физическое лицо (для бесплатного приложения без покупок достаточно).
- Проверка личности — по требованиям RuStore на момент регистрации (для граждан РФ обычно через Госуслуги). Если живёшь не в России, сначала проверь в консоли, какие варианты доступны.

## 2. Файл для загрузки
- `umnozhenie.apk` (собирается `./build.sh`), подписан ключом `upload.jks`.
- RuStore требует, чтобы все обновления были подписаны **тем же ключом** — храни `upload.jks` и пароль (связка ключей macOS: `umnozhenie-upload-key`) в надёжном месте.
- Пакет: `com.alex.umnozhenie`, версия берётся из `app/AndroidManifest.xml` (versionCode/versionName). Для каждого обновления versionCode нужно увеличивать.

## 3. Карточка приложения
- **Название:** Таблица умножения: правила
- **Краткое описание (до 80 символов):** Учим таблицу умножения: простые правила, рифмы, картинки и тест с подсказками
- **Полное описание:** то же, что в `listing.md` (раздел «Полное описание»).
- **Категория:** Образование (если есть подкатегория — «Для детей»).
- **Возрастное ограничение:** 0+
- **Иконка:** `icon-512.png` (512×512)
- **Скриншоты:** `screenshots/1-home.png` … `4-correct.png` (1080×1920)
- **Баннер (если попросят):** `feature-1024x500.png`
- **Политика конфиденциальности:** https://razkevich.github.io/umnozhenie/privacy.html
- **Сайт / поддержка:** https://github.com/razkevich/umnozhenie
- **E-mail поддержки:** укажи свою личную почту (будет видна пользователям)

## 4. Анкеты
- Монетизация: бесплатное, без рекламы, без встроенных покупок.
- Сбор данных: не собирает; разрешений не запрашивает; работает без интернета.
- Целевая аудитория: дети и родители.
- RuStore SDK (платежи, пуши, отзывы) не нужен.

## 5. Отправка
Загрузить APK → заполнить карточку → «Отправить на модерацию». Модерация обычно занимает от нескольких часов до нескольких рабочих дней.
